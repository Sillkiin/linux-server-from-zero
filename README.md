# Linux-сервер с нуля

[Открыть интерактивный учебник](https://sillkiin.github.io/linux-server-from-zero/)

Русскоязычная инструкция по администрированию Linux-сервера для новичка,
знакомого с Windows. Учебные команды разобраны для Ubuntu Server 24.04 LTS.

Начни с кнопки **«Начать с простого»** или раздела **«Как заниматься с нуля»**.
Памятка объясняет, где вводить команды, как сохранять файл в nano и как
различать команды Windows, команды Linux и содержимое конфигураций.

- 20 блоков: пользователи, права, пакеты, SSH, службы, сеть и firewall,
  диски, Nginx, приложение, база, Samba, копии, расписание и диагностика.
- 24 пошаговые сцены, 69 карточек команд и конфигураций, 85 терминов.
- 20 коротких вопросов и тренировка: 15 случайных вопросов из банка 41.
- 8 расследований с моделью терминала, карта файлов и калькулятор прав.

[Подробная инструкция в PDF](Linux-server-guide.pdf) ·
[Редактируемый текст в Markdown](Linux-server-guide.md)

На iPhone открой сайт в Safari. Для значка на телефоне:
**«Поделиться» → «На экран “Домой”» → «Добавить»**.
Дождись статуса **«Уроки сохранены»** с интернетом. Основной материал после
этого доступен без сети; внешние источники и файлы PDF/Markdown отдельно
требуют загрузки. Браузер может очистить кеш.

Прогресс хранится в браузере на данном устройстве и не синхронизируется.
Учебный терминал — симуляция внутри страницы. Настоящие команды выполняют
отдельно на своей учебной ВМ. Успех в модели не подтверждает состояние сервера.

Сайт статический: HTML, встроенные CSS/JS, значки, манифест и service worker.
Данные реального сервера и учётные данные здесь не используются.
